# Idea propuesta: LeadProof Agent (Open Agent Hackathon 2026)
Track: Wildcard [Tinkerer] (BYOP sobre AutoAI Lead). Obligatorio: integrar Zetaris + Meterless; solo se califica el trabajo nuevo. Plan B: Track 02 "The Agent That Can Explain Why".

Qué hace: un agente que, para un negocio local, junta prospectos de fuentes dispersas (CRM, hojas, sitios web, Maps) y explica con evidencia por qué contactar a cada uno. Después redacta el primer mensaje y lo deja para aprobación humana.
- Zetaris: consulta federada sobre las fuentes dispersas sin copiar datos ("fragmented intelligence").
- NVIDIA Nemotron: razonamiento y puntaje con citas de evidencia (compite también por "Best use of Nemotron").
- Meterless: medición y cobro por uso, por cada lead calificado (modelo de negocio de la agencia).
- Space XAI / Cursor: construido con Cursor (compite por "Best use of Cursor-built product").
Demo (≤3 min): conectar 2 fuentes → ver ranking con evidencia → aprobar mensaje → ver cargo en Meterless.
